Design a crowdsourcing quality check
  • Recruit through more than one channel; check who is missing.
  • Give contributors clear definitions and examples.
  • Check duplicates, inconsistent reports and a subset against another source.
  • Record uncertainty and give contributors a correction process.
Crowdsourcing draws contributions from many people. Citizen science involves public participation in scientific research; it is not a synonym for every online survey. Larger participation can increase scale while leaving systematic bias.

    Connect threats to specific protections
    A message demanding a password urgently, a request to install an unknown attachment, and an unexpected Wi-Fi login screen require different checks. Use a known trusted route to verify requests, inspect source and context, avoid entering credentials into unverified prompts, and maintain software updates. The lesson asks you to explain the mechanism and a remaining limitation; a security label alone is not an explanation.

    Write a responsible project recommendation
    Combine evidence from the four workspaces. Recommend how the Community Shade Map should collect, analyse and share information.
    1. Choose an access plan within the stated budget; give a result and one excluded group or untested assumption.
    2. Compare the 32% raw sample and 44% population-weighted model result; state why weighting alone is not a guarantee.
    3. Choose fields, a release format and a security measure. Explain both the mechanism and a remaining risk.
    4. Select an asset, a permitted action and an appropriate source/changes record. Explain how you would resolve unknown permissions.
    Reasoning, not a single preferred opinion
    A strong recommendation identifies a stakeholder, a specific benefit or harm, evidence, a feasible action and a limitation. Different recommendations can be well supported. Do not turn an access percentage or a checklist into a universal “ethical score”.
    Open-source code is supplied under terms that allow uses such as inspecting, modifying and sharing code. Open access makes research literature freely available and supports reuse under its applicable terms. Neither term means that every work may be reused without following its actual conditions. Giving credit does not itself create permission.
