Can run-length encoding make a file larger?

Our toy format uses one byte for each raw letter. Each encoded pair uses one byte for a count (1–9) and one byte for the symbol. Long runs split into pairs, so ten A characters become 9A1A. Shared format instructions and metadata are excluded.

This toy encoding is one lossless example. It does not model ZIP, image or audio file formats. Whether a method compresses well depends on the data and the overhead of its format.

A fictional campus commute survey

16 raw records from a simulated voluntary survey at one school on one morning. These are synthetic classroom examples, not actual student records or research findings.

Read the metadata and cleaning rules first
  • id: response identifier; repeated IDs can reveal duplicates.
  • mode: main travel mode; canonical labels are Walk, Bike and Bus.
  • minutes: reported one-way time in minutes; blank means missing.
  • distance_km: reported one-way distance in kilometres.
  1. Trim and standardize mode labels.
  2. Keep the first identical response for a repeated ID. Investigate conflicting duplicates before analysis.
  3. Exclude missing or negative times from this analysis and log the exclusions.
  4. Retain the 120-minute observation, but flag it. Unusual does not automatically mean wrong.
