3. Original network case: prove a path or a break

Only the four drawn links exist; all nodes are working. If A–T fails, can S still reach T? Give a valid path. If both S–A and S–B fail, can the remaining links restore reachability? Explain.

Show answer and reasoning / 展开答案与解释

After A–T fails, S → B → T remains a valid path. If S–A and S–B both fail, S has no outgoing link in this model, so it cannot reach T. Having two initial routes does not protect against every set of failures.

Reachability is a claim about a path. It is different from a claim that every packet arrives, arrives in order, or arrives quickly.

教师支持：学生必须给路径或断开的理由，不接受只写“有冗余所以可以”。先检查每一步边是否仍存在；把节点全好和只有四条边作为模型条件，避免学生自行加连接。

4. Original sampling case: mix and bias

A fictional library asks whether more charging points are needed. In this synthetic model, the shares answering that more charging points are needed are 25% among weekday users and 75% among weekend users. These fixed within-group need rates are not questionnaire participation rates. Using the supplied rates, calculate the sample estimate and the population-weighted reference. Explain one limitation of reweighting.

Show answer and reasoning / 展开答案与解释

Sample: 0.90 × 25% + 0.10 × 75% = 30%. Population-weighted reference: 0.60 × 25% + 0.40 × 75% = 45%. The reference is 15 percentage points higher. Matching group shares does not remove within-group nonresponse, selection or measurement bias; 45% relies on the supplied rates.

教师支持：这些都是合成数据，45%不被描述为现实真值。若学生把25%与75%直接平均得50%，让其指出用了什么未经给定的50/50权重。

5. Original reading case: access is not permission

Figure F

The creator permits reading only. A student wants to copy the figure into a public library page and add the author’s name.

Icon I

A simplified classroom card permits sharing and adapting if the creator is credited and changes are identified. The student recolors the icon.

For each item, give a supported next action. Identify which part of your reasoning is about permission and which part is about attribution.

Show answer and reasoning / 展开答案与解释

For F, get permission covering reproduction or choose a permitted replacement before reuse. Credit alone does not expand reading-only permission. For I, follow the given sharing/adaptation permission by crediting the creator and stating the recoloring. These are simplified case terms, not complete license texts.

教师支持：要求学生引用具体条款，不凭免费、在线或无水印判断。题目不需要法域例外或法律推测；合法使用与伦理评价也不应被混成同一个标签。

6. Repair a claim without overclaiming

Choose one CED sample error and one original case. Write: the supplied condition, the evidence, the conclusion, and a limit. Use a path for a network claim, a weighted calculation for a sampling claim, or an explicit permission for a reuse claim.

Exit check: why does “there is a backup route” not prove “every message will arrive”?

Show answer and reasoning / 展开答案与解释

A backup route supports connectivity under certain failures. It does not by itself establish a delivery protocol, eliminate loss, or cover all possible failures.

教师支持：78–86分钟把官方样题错因迁移到新情境；最后4分钟用一句因果解释检验是否能区分模型支持与没有检验的保证。
