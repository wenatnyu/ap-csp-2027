Teaching this chapter / 教学安排

这是本课程自定的第一章，跨越官方 Data、Creative Development 和少量 Algorithms and Programming 内容。章末目标：学生既能解释信息表示，也能独立写出、追踪并测试一个简单顺序程序。

Lesson课堂可观察成果课后检查
01 · Bits & Binary正确区分“编码数量”和“最大数值”；解释溢出与舍入。二进制转换与表示题；30 分。
02 · Innovations用目的、用户、输入、处理和输出解释一个计算创新。Library Room Finder 情境分析；30 分。
03 · Variables先预测再运行；用追踪表说明每次赋值，修改票价程序。赋值、表达式、输入输出与程序修改；30 分。
04 · Test & Improve完成需求、程序、测试证据、反馈和修订记录。整章掌握检查，覆盖四课；30 分。

使用方式

  1. 课堂打开每课 Slides；题目答案默认折叠。N 显示教师备注，Reading view 适合小屏阅读。
  2. 课后发 Student PDF；教师使用 Answer key 逐点评分。网页 Homework 可供讲评时逐题展开答案。
  3. 第 3、4 课的编程页使用 AP 伪代码的有限教学子集。学生先写预期结果，再运行、对照和解释；第 4 课将代码改成每单收取 3 的手续费。
  4. 第 4 课作业作为章末检查：二进制、创新分析、代码追踪、测试分别诊断。对错因补练后，再进入下一章。

Ticket Total / 第 4 课项目验收

有效输入是 1–50 的整数票数。每张票价格 12，每笔订单手续费 3；输出总价。程序需要使用输入、变量、算术、顺序和输出。至少检查票数 1、2、50，记录预期与实际结果，并说明一次修改的原因。

这是基础编程练习，不是正式 Create 任务，也不具备正式 Create 的全部要求。普通课堂与此练习的时间不能替代正式 Create 的专用课堂时间。这里的章节顺序与分数为教师自定，不是官方单元编号或 AP 最终分数。
