本课目标与前置知识

本课以第一章的变量赋值和顺序执行为起点，补齐算术表达式与字符串表达式。学生要能读出运算顺序，解释 / 与 MOD 的不同结果，按给定规则连接字符串、提取子串，并写出可测试的顺序程序。阅读者应有基本乘除法知识；尚不要求 IF、循环、列表、自定义过程或机器人。25分钟项目应保护，不以整节教师演示代替学生实际编写。

英文投影片配中文术语与 N 键教师备注。练习先个人预测、再同伴说明、最后展开答案。图中分组、位置和数据流是解题支架；不把能照图数出结果当作已经能独立编程。所有题目与课堂量表原创，课堂活动不等同正式 Create 任务或官方 FRQ。

本课字符串过程契约

过程给定规则教学检查
CONCAT(a, b)a、b 都是字符串；按顺序连接并返回新字符串，不自动添加空格。CONCAT("Hi, ", "Ada") 为 "Hi, Ada"；空格来自第一个参数。
SUBSTRING(s, start, length)位置从1开始，返回 start 起的 length 个连续字符。本课使用正长度及有效范围。SUBSTRING("PLANET",2,3) 为 "LAN"；第3参数是数量，不是末尾位置。

CONCAT 与 SUBSTRING 在此是实验室提供的教学过程；AP题若给出其他定义，应按该题定义。官方固定参考表没有这两项字符串内建过程。官方 LENGTH(aList) 对列表定义；即使实验室提供字符串 LENGTH，本课也不把它当官方字符串内建规则，不要求使用。本节仅用简单英文字符，避免把 Unicode 码点、编码单元或屏幕字形混为字符位置。

Workshop Pass：具体任务与教师参考

假想工作坊参与者输入姓名和活动分钟数，程序输出问候语、姓名前两字符的badge code、十进制小时，以及除去完整小时后余下的分钟。姓名至少两个英文字母；分钟为0至180整数。该badge code 不保证唯一。项目只按有效输入假设设计，本节不增加尚未学习的条件验证。

输入队列每行一个 JSON scalar，例如第一行 "Ada"，第二行 105。每个测试要重新设置整个队列；INPUT 按顺序读取。数字不要加引号。数值标签与值分开 DISPLAY，避免依赖未定义的字符串与数值隐式转换。参考表 DISPLAY 关注输出的值及顺序；实验室可能按行排列输出，不据此改变求值规则。

教师参考程序：学生开始编写后按需要使用
name ← INPUT()
minutes ← INPUT()
greeting ← CONCAT("Hello, ", name)
badge ← SUBSTRING(name, 1, 2)
hours ← minutes / 60
remaining ← minutes MOD 60
DISPLAY(greeting)
DISPLAY(badge)
DISPLAY("Hours:")
DISPLAY(hours)
DISPLAY("Remaining minutes:")
DISPLAY(remaining)

每人保存代码、预期与实际输出、一次具体反馈和修改说明。建议8分课堂量表：输入顺序1；问候语正确1；badge正确1；小时正确1；余下分钟正确1；三个有预期的有效测试1；输出标签清晰1；记录修订与复测1。该量表由教师设计，不是AP官方评分标准。

误区、支持与延伸

  • 所有表达式都从左到右。 用同一数值比较有无括号，先圈出最先运算。
  • 整数相除只得到整数。 用8份平均分给5人画份额，区别数学商与完整组数。
  • MOD 是商、百分比或可等于除数。 用 a = q × b + r 检查，要求0 ≤ r < b。
  • 子串第3参数是结束下标。 先标位置，再从 start 数 length 个字符；不要按记忆猜名称。
  • 连接自动插空格或改原字符串。 明确两个返回值调用都不自动重写源变量。
  • 重新赋 minutes 就自动更新 hours。 在状态表只改赋值左侧，要求指出第二次更新 hours 的语句。

支架：先纸上索引卡，再代码；给输出清单和两个 INPUT 起始语句，不给完整答案。较快学生可以为问候语增加一个明确字符串前缀，或解释为何105比180更能检查除法错误；不要提前加入 IF、循环或假装badge唯一。采用精确小数示例，浮点表示误差会在其他适当情境处理。

作业与出口检测

12题共30教师分，约40分钟：Q1–6每题1分，其中Q5恰选两项；Q7–12每题4个独立得分点。网页答案隐藏；单独教师答案PDF含干扰项解释与逐点评分。作业额外提交Workshop Pass代码与测试记录，不重复计入30分。
