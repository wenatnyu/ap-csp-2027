3. R01与R02：先找第一次推理偏离

R01：五类教学标签为Condition、Trace、Concept、Evidence、Pacing。标签必须附事实，不能只写“粗心”。五位编码33个不同标识不够：32是模式数，31是无符号最大值，两者别混。赋值微例输出4、7；saved保存的是赋值当时的4，并非与first永久关联。更多志愿者回复仍可能重复同一种选择偏差。

R02列表：[2,5,8]在当前位置2前插入7得到[2,7,5,8]，再删当前索引4得到[2,7,5]；显示第3项与长度得到5、3。每次编辑后重新标索引。不要按原始位置删元素。

R02过程：错误sumBelow将RETURN放在FOR EACH内部，对[4,10,7]和limit 8只处理4就返回4。移到循环后才得到11。返回结束整个当前过程，不只是离开IF；也不能泛化为所有提前RETURN都错误，行为应由需求决定。

修正后limit为4、5、8时分别返回0、4、11；空列表返回初始化的0。课后[3,8,12]配limit 8返回3，改用≤后为11。边界必须针对运算符与输入范围，而不是随机试数。

R02搜索：示例有序列表为[4,9,16,23,31,42,60]。线性搜索只在找到目标或到达表尾时结束；二分取较低中点，一次元素检查计一次比较。找4：线性1次，二分23→9→4共3次；找60：线性7次，二分23→42→60共3次；找30：线性7次未找到，二分23→42→31后空区间，共3次。目标16两者均3次。不要引入线性提前利用排序停止的新规则，却仍沿用本题计数。

困难学生先填一个正确状态，再逐步延伸；熟练学生构造一个反例，解释为何某个具体输入上更快不等于最坏增长更好。所有微例为原创复习材料，不能拿来替学生完成正式Create作品。

4. R03：用不同证据支持不同主张

先打开完整本地官方PDF做CED样题，避免抽取文字时丢图。若阅读器不响应页码锚点，手动输入PDF182；答案PDF194对应印刷187。核答案后，用新情境测试学生是否会迁移，而不是只记住官方字母答案。

网络微例：只有S–A、A–T、S–B、B–T四条边，节点都正常。A–T断开仍有S→B→T；S–A与S–B都断开时，S与剩余网络断开。路径证明只支持给定故障下的可达性，不保证顺序、速度、无丢包或所有故障下交付。

采样微例：虚构图书馆各组中回答“需要更多充电点”的比例为weekday 25%、weekend 75%；这不是问卷参与率或回收率。样本90/10得30%，人口60/40加权参考得45%，差15个百分点。50/50样本则得50%。这些差异来自混合权重；组内非响应、选择及测量偏差仍可能存在。数据是合成假设，45%不是现实真值保证。

许可微例：Figure F只允许阅读，署名不创造复制许可；可在复用前请求相应许可或替换。Icon I按已给简化卡可以分享/改编，但须署名并标出修改。学生必须指出条件，不凭“免费、在线、无水印”推断权利，也不靠未给出的法律例外答题。

三种证据形式分别是路径、权重计算、许可条款。复盘时让学生明确“这条证据支持什么”和“还不支持什么”，避免所有题都用含糊的“更安全、更公平、更有效”。

5. R04：正式作品讲评的前置条件与评分范围

必须在正式Create九小时之外安排。教师引导讨论正式作品、PPR或相关回答，须等三个正式组件全部Submit Final之后。正式任务尚未开始时，可用此前个人练习程序并说明无法完整模拟正式PPR条件。若正式任务已经开始而任一组件尚未Final，则推迟本课指导讲评；即使换成旧个人程序，practice written responses的教师反馈仍须等三项全部Final。独立自查不等于允许教师反馈，不能用它充作本课20分钟指导讲评。

0–10分钟只准备阶段、材料、可读性和答题方式，不提前揭示本套评分点。计时60分钟仅使用本人的PPR/已明确标为练习的参考，以及当前考试允许的通用参考资料；完整源程序保留到讲评时核验，不当作考场额外参考。教师不挑截图、不代写响应。

方法是command → own code evidence → causal explanation：先确定题目让回答做什么，再指出实际要求的具体对象，最后依据当前值和执行路径解释为什么。不能只列术语、描述一般算法，或编造一个自己的程序实际上不会出现的行为。

仅在70–90分钟复盘：按当年原卷检查文档帮助的对象、指定循环的终止、接受参数范围内的调用行为，以及移除列表后保持行为的要求。2026不能一律套成“描述程序目的”；详细条件回到对应原卷与评分指南，本文不重印题干或代写答案。

2026评分指南有6个一分行：视频1行、程序要求1行和书面4行。本课只记录Q1、Q2(a)、Q2(b)、Q2(c)四个书面行的练习表现。每行依据完整条件判断，不把其内部要点自行拆成所谓官方半分；课堂不由四行表现预测AP等级。也不能用某个单行评分的宽松条件反向删掉Student Handouts中的正式提交要求。

学生保留首次限时作答，并自己修订一段论证。已最终提交的程序不能因为本课发现不足而随意改交；解释应反映已有代码的真实行为。不同学生作品不同，不存在统一的完整内容答案；正式程序、PPR和视频不公开上传课程网站。

6. R05：把复测变成下一步行动

20题34分钟是缩短的混合练习，不是70题120分钟选择题卷。看答案前记录自信程度；34–60分钟优先找“自信却错”和“猜对但不会解释”的项目。每题至少留下决定性条件、正确证据及一个干扰项为什么错，不能只抄解析。

60–70分钟只针对一个机制做变式。代码例每次循环都清零再加2，所以三次后显示2；保留循环前初始化、移除循环内清零才能累加得6，零次循环仍显示0。数据例2,000压至1,500字节，省500字节即25%，剩75%；两种百分比不可互换。

70–80分钟核实际考试准备，80–90分钟形成两个有日期的修复行动与一次合适的完整练习安排。完整MCQ需通过获授权的学校教师资源；公开2026/2025/2024套卷能支持完整WR题组训练。小题组不改名为完整模考，Bluebook预览也不当成计分练习卷。

Bluebook预览用于界面熟悉，不计时、无成绩或答案反馈。安装、账号恢复与重要技术故障在课前处理；实际考试地点与安排由学校确认，PPR最终状态及打印问题通过教师/AP Coordinator处理。本地学习记录不代表官方报名或收件。

7. 教师核查与后续轮换

本章评估关注条件识别、执行准确、证据选择、因果解释与变式迁移。课堂自查不是College Board认证。面对同一错误，先确定机制再选一小项练习；只有复测仍出现同类问题时再加练，不用整套重刷掩盖未理解的原因。

后续可依次选择未做过的2025 Set 1、2025 Set 2、2024 Set 1、2024 Set 2；顺序只是教学建议，不是官方难度排序。每次将原卷与同年同Set评分配对，先独立完成再看评分和学生样例。各套入口已有于官方资源页，不下载或再发布受限材料。

收尾记录：学生的两个修复目标是否有新案例验证，剩余问题是否明确归类，下一次完整训练的材料与时间是否落实。课程资料完成不等于个人掌握已完成；需要根据真实证据持续调整。
