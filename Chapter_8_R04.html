CHAPTER 08 · R04 · 90 MIN

The 2026 Written-Response Paper

2026官方完整书面题组与证据讲评

10 minutes of preparation, 60 minutes of independent official written responses and 20 minutes reviewing the four written scoring rows.

Learning goals / 本课目标

  • Read the current prompt rather than substitute a memorized answer.
  • Support a response with precise evidence from personal program code.
  • Explain why the code produces the claimed behavior.
  • Use the four written scoring rows without treating practice as a full Create or AP score.

1. Prepare a valid practice context · 0–10 min

Schedule this guided lesson outside the nine dedicated task hours. If all three Create components are final, you may use that work for guided review. If the official task has not yet begun, you may use a separate earlier personal practice program. If the official task has begun but any component is not final, postpone this guided lesson: switching to an older program does not permit teacher feedback on practice written responses.

Have a readable PPR and keep the corresponding full program for post-attempt checking. During the 60-minute attempt, use your PPR and the general reference information allowed in the exam, not extra access to the full program. If you have not yet begun the official task and use earlier work, label the attempt “personal practice program.” That can develop the reasoning skills, but it does not fully simulate using an official submitted PPR.

教师支持：先区分三状态：全Final可讲评；正式任务尚未开始可用旧个人练习；正式任务进行中则推迟本课指导讲评。换旧程序不能绕过practice WR反馈限制。准备10分钟不替学生制作PPR或挑截图；缺材料者记录缺口，不发全班可背的统一程序。

2. Complete the 2026 written-response paper · 10–70 min

Open the official 2026 complete written-response paper

Work independently for the full 60 minutes. Answer both questions and all four prompts using the supplied official directions and your own code evidence. Do not read the scoring guidelines during this interval.

This is the complete publicly released written-response paper. It is not a full AP exam simulation: the 70-question multiple-choice section and the Create artifacts are not being assessed here.

教师支持：保留连续60分钟，不边做边讲。不要把以往年份的通用“程序目的”回答套到2026年题干；命令、对象和条件必须从当前原卷读出。这里链接原题，不复制题文。

3. Connect the command to evidence and a reason

Locate precisely

Identify the requested procedure, list, condition, loop or call in your own material. Check that it is the one the prompt specifies.

Explain the mechanism

Follow the actual values and control flow. A statement such as “the code is correct” does not explain what causes the result.

Respect the question

If a prompt asks for a case or an impossibility explanation, decide which is supported by your own program. Do not invent behavior to match a memorized response.

Keep material separate

These review notes are practice support. They do not belong inside a PPR and are not a prepared answer to an official prompt.

教师支持：这是一种读题和论证方法，不是可直接填入考试的万能答案。教师用学生已允许讲评的材料追问证据，不代写句子或改动已最终提交的程序。

5. Revise the explanation, not the submitted artifact

Choose one response that lacked evidence or a causal link. Without changing the submitted program, identify what its existing code actually supports. Rewrite the explanation to address the prompt directly; if the code cannot support the requested claim, explain that limitation honestly.

Keep the first timed attempt and the revision together. For later independent practice, choose an unused public paper from the official-paper index.

教师支持：三项全部Final后可按规则教学反馈；已提交内容不因为本课复盘就可自由改交。不要给全班同一个所谓完整答案。若在正式任务开始前用个人练习程序，明确本次结果不能证明正式PPR在考场可用。

After class / 巩固

  • Keep the original timed response and a revised explanation for one weak written row. Identify exactly which evidence was missing.
  • Use a different unused public written-response paper for a later independent attempt; check its own year-specific guidelines.
  • If you used personal practice material, list what is still needed to simulate access to an official submitted PPR accurately.
