CHAPTER 08 · R02 · 90 MIN

Repair Code & Algorithm Reasoning

代码、算法与边界补弱

A 20-minute targeted set followed by original list, return-position, parameter, boundary and search comparisons.

Learning goals / 本课目标

  • Trace edits using the current 1-based list indices.
  • Explain how RETURN placement and meaningful parameters affect execution.
  • Use boundary cases to test a correction.
  • Compare search costs under stated assumptions.

1. Start at the first state change

The aim is to explain execution, not memorize a pattern. Track indices, argument values, branch decisions and the exact point at which a procedure returns. All code below is original review practice, separate from official Create work.

教师支持：先用R01记录选一个代码弱点。正式Create若尚未三项Final，不在本课让教师改学生正在提交的程序；这些原创小例独立于正式作品。

2. Complete Q11–Q20 in 20 minutes

Open the original algorithms set

Work independently. Draw a tiny list or trace table when needed. If you are unsure, record the first uncertain step rather than repeatedly changing the answer.

教师支持：10–30分钟完整独立作答，剩余时间用于实际修复。不要在限时中逐题宣布对错；评分反馈留到限时结束后。

3. List indices belong to the current list

items ← [2, 5, 8]
INSERT(items, 2, 7)
REMOVE(items, 4)
DISPLAY(items[3])
DISPLAY(LENGTH(items))

Predict the list after each edit and both outputs. AP list indices start at 1; INSERT places the new element before the current element at the specified position.

Show answer and reasoning / 展开答案与解释

After INSERT: [2, 7, 5, 8]. After REMOVE at the current index 4: [2, 7, 5]. The outputs are 5 and 3. REMOVE acts on the edited list, not the original positions.

教师支持：图只给初始位置，不提前填修改后答案。学生应在每次编辑后重画索引；误把8的旧索引3保留下来，属于当前状态追踪错误。

4. A return ends the procedure

This program is intended to sum all values below limit. For values [4, 10, 7] and limit 8, predict what the buggy procedure actually returns, then locate the smallest repair.

PROCEDURE sumBelow(values, limit)
{
  total ← 0
  FOR EACH item IN values
  {
    IF (item < limit)
    {
      total ← total + item
    }
    RETURN(total)
  }
}
Show answer and reasoning / 展开答案与解释

It returns 4 after processing the first item. RETURN is inside the FOR EACH body, so later items are never processed. Move RETURN after the loop:

PROCEDURE sumBelow(values, limit)
{
  total ← 0
  FOR EACH item IN values
  {
    IF (item < limit)
    {
      total ← total + item
    }
  }
  RETURN(total)
}

The repaired call returns 11 because 4 and 7 are below 8. The change in location, not a change in the comparison, repairs this bug.

教师支持：只改一处定位并复测。RETURN不是只跳出IF或本次循环，而是结束当前过程。此例考察位置和执行含义，不让学生背“所有RETURN都只能在最后”；提前返回在别的需求下可能正确。

5. Make the parameter and boundary visible

Use the repaired sumBelow. Predict the following before checking. Changing limit must affect which items contribute; equality matters because the comparison is strict.

CallYour predictionWhat it tests
sumBelow([4, 10, 7], 4)Write firstEquality excluded
sumBelow([4, 10, 7], 5)Write firstOne value included
sumBelow([4, 10, 7], 8)Write firstTwo values included
sumBelow([], 8)Write firstZero iterations
Show answer and reasoning / 展开答案与解释

The results are 0, 4, 11 and 0. The empty list leaves total at its initialized value, and RETURN after the loop still runs. The parameter changes membership in the sum; merely naming a parameter would not establish this effect.

教师支持：边界不是随机挑几个数字：4刚好等于列表元素，5跨过它，空列表检查零次循环。若改成≤，第一项结果会从0变4，要求学生用这个反例说明运算符的作用。

6. Same result can have a different cost

Compare a left-to-right linear search with binary search on the displayed sorted list. The linear search stops only when it finds the target or reaches the end. Count each inspected element once. How many inspections find 4? How many find 60? What happens when searching for 30?

Show answer and reasoning / 展开答案与解释
TargetLinear searchBinary search
41 inspection23 → 9 → 4: 3 inspections
607 inspections23 → 42 → 60: 3 inspections
307 inspections, not found23 → 42 → 31: 3 inspections, then interval empty

For 4, linear search happens to be cheaper. This does not overturn binary search’s better worst-case growth on sorted data. Binary search needs the ordering assumption; neither method can report a missing value as found.

教师支持：明确比较单位是一项元素检查，不是源码比较运算符计数。二分未命中时空区间结束；不能把31当作最近值返回。讲效率要区分具体输入与最坏情况，不背“二分每次都更快”。

7. Explain one repair without copying the example

Choose one algorithms-set error. State its first incorrect index, branch, return or comparison. Give a boundary test or counterexample that would expose the mistake, then explain why your correction changes the result.

Exit check: changing RETURN’s position and changing a parameter can both change output. Explain their different mechanisms.

教师支持：74–85分钟让学生实际重做专项错题或自造反例；85–90分钟检验是否能把“参数决定哪些值参与”和“RETURN决定何时结束”分开解释。
