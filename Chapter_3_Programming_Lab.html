Language and execution model / 支持范围
This classroom subset supports assignment, INPUT, DISPLAY, numeric + − * / MOD, comparisons, true/false, NOT/AND/OR, IF/ELSE, nested blocks, REPEAT n TIMES, REPEAT UNTIL, and RANDOM(a,b). Integers returned by RANDOM include both endpoints. Variables are case-sensitive; comments begin with //.
REPEAT UNTIL checks before entering its body. If the condition is already true, it runs zero times. The condition is the stopping rule. Counted-loop counts are evaluated on entry; examples keep the count unchanged during the body. Each control check is visible in the trace.
For L09, we define three classroom string procedures: CONCAT(a,b) joins two strings; SUBSTRING(text,start,length) takes the stated number of characters from a 1-based position; LENGTH(text) counts characters. They are explicitly defined for these exercises. The official reference sheet's LENGTH is a list operation; it does not define these string procedures. Use the English-character examples in the lessons.
Inputs must be scalars. Lists, custom procedures, robot commands and string ordering are taught later and are not implemented here. Compare matching types; arithmetic needs numbers and Boolean operations need true/false. This lab evaluates both sides of AND/OR; do not rely on skipping a potentially invalid expression. Use nested selection when a check must precede another operation.
The lab uses finite browser numbers and stops after 3,000 visible steps. That stop is a classroom safeguard, not proof of an infinite loop or an AP execution rule. Each DISPLAY appears on a new line here; official DISPLAY appends a space. Editing code or inputs resets execution, while your prediction stays.
