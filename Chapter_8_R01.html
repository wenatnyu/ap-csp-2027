CHAPTER 08 · R01 · 90 MIN

Diagnose the Five Big Ideas

五大主题诊断与错因分类

Use an 18-minute original diagnostic to separate reading, tracing, concept and evidence errors before choosing repair work.

Learning goals / 本课目标

  • Identify decisive conditions before solving a question.
  • Trace current values instead of guessing program behavior.
  • Use evidence to classify errors and choose two repair targets.

1. Diagnose before choosing what to review

Use ten new, original questions to find repair targets across the five Big Ideas. The result is a small diagnostic sample, not an AP score prediction.

教师支持：不要把10题得分换算成AP等级。先看学生错误集中在哪些机制：读题条件、执行追踪、概念边界或证据表达；本节诊断用于选择补弱内容。

2. Complete Q01–Q10 in 18 minutes

Open the original diagnostic set

Work independently for 18 minutes. For every answer, mark confident or uncertain on paper. Read words such as exactly, at least, only, sorted and same before calculating. Do not open feedback until the independent interval ends.

教师支持：0–8分钟先讲方法，8–26分钟完整保留给独立10题。读题标记不意味着必须把题干所有字划线，只提取会改变结论的条件。自信度应在看答案前记录。

3. Micro-case: a condition changes the answer

Original review case. A club needs 33 distinct identifiers. Every identifier must use exactly five bits. Is that enough? Explain what must change if the club keeps all 33 identifiers.

Show answer and reasoning / 展开答案与解释

Five bits provide 2⁵ = 32 patterns, so 33 distinct identifiers do not fit. At least six bits are needed because 2⁶ = 64. The decisive conditions are “distinct,” “33” and “exactly five bits.”

A useful correction names the limiting quantity. “Use more memory” is less precise than identifying the number of available patterns.

教师支持：这里考的是模式数量，不是五位无符号整数的最大值31。要求学生区分32种模式与最大数31；这也是把条件标记转化为具体推理的示范。

4. Micro-case: save a value, then change a variable

Predict both outputs before running or revealing anything. Record the value of each variable after every assignment.

first ← 4
saved ← first
first ← first + 3
DISPLAY(saved)
DISPLAY(first)

The outputs are 4, then 7. The assignment copied the current value into saved; later changing first does not change saved.

If your prediction was 7, 7, classify the error as execution/assignment reasoning, then explain the exact statement where your model diverged.

教师支持：不能只抄最终4和7。让学生指出第二条赋值完成时saved存了什么；把错误定位到一个执行时刻，下一课的列表和过程追踪会沿用同一方法。

5. Turn feedback into an error record

Classroom tagEvidence to recordA useful repair
ConditionThe exact word or constraint I missedRestate the rule, then change one condition.
TraceThe first incorrect state or pathRebuild the trace from that point.
ConceptThe two ideas I confusedWrite a distinction and a counterexample.
EvidenceThe claim I could not justifyPoint to a value, code step or stated permission.
PacingWhere time was spent without progressSet a return point and finish other items.

Example: “A larger volunteer sample must be unbiased” confuses quantity with representativeness. Explain a selection or nonresponse mechanism; simply asking more volunteers may preserve the same bias.

Show answer and reasoning / 展开答案与解释

A defensible counterexample is a survey available only through one club’s app. More replies from those app users can still underrepresent non-users. Bigger is not automatically more representative.

教师支持：这些标签是本课程复盘工具，不是官方评分分类。一次错误可以有主因与次因，但本课每题先写一个可行动主因，避免笼统归咎于粗心。

6. End with two specific repair targets

Choose two questions: one incorrect answer and one correct answer you guessed. For each, write the decisive condition, a corrected explanation and a new case that would test the same idea. Assign each target to code/algorithms, data/networks/impact, or reading and pacing.

Exit check: explain the difference between “I now know the answer” and “I can apply the rule to a changed case.”

教师支持：70–85分钟让学生实际改一个条件并再答，教师按解释核查；85–90分钟收两项目标。不要以反复点击直到正确作为掌握证据。

After class / 巩固

  • Revisit one missed diagnostic item without looking at feedback; explain why each alternative fails.
  • Create one small changed-case check for a repair target and state the expected result.
  • Keep your original answer, confidence and correction; do not replace the record with only a new score.

打印复盘记录单

教师课后复盘与分层支持
  • 保留完整18分钟独立诊断，不用讲题挤占。10题只提供薄样本，不以总分预测AP等级。
  • 要求圈定条件、显示追踪过程；错误标签是教学工具而非官方评分术语。
  • 两项修复目标分别指向具体机制与证据，不写笼统“多刷题”。
