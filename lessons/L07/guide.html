Lesson 07 · Metadata, Data Quality & Cleaning

自编 Chapter 2 · 23 slides · 90 minutes · AP CSP May 2027 preparation

本课定位与准备

本课先解决“这些值是什么意思、来自哪里、如何成为当前分析可用的输入”，再让 L08 讨论统计和图表结论。学生应已理解二进制值需要上下文、程序的输入—处理—输出、有效输入与测试规则。本课不要求写列表处理代码；使用现成的数据实验室执行透明规则，并留下可核对的记录。

主数据源为data/chapter2-commute.json，实验入口为Chapter 2 Data Lab → Data tab。这是一份合成教学数据：设定为一所虚构学校某天早上的自愿通勤问卷，不含真实学生记录，也不是研究发现。不要要求学生上交本人地址、定位、姓名或真实通勤轨迹。

投影英文为主，教师备注中文。N 打开备注；答案逐题展开。准备纸笔或学习记录页，先预测规则的结果，再运行程序核对。均值、中位数和图表虽可能在实验室界面可见，本课仅核对行、字段和日志；数值解读留到 L08。

固定数据、固定默认规则

字段：id 为响应标识符；mode 的规范值为 Walk、Bike、Bus；minutes 为单程经过时间（分钟），空值表示未知，负数无效；distance_km 为单程距离（千米）。保留 ID 前导零。原始表有 16 行、15 个不同 ID，ID 03 有一份完全相同的副本。行数与不同响应数不应混用。

原始观察默认处理理由与记录
ID 09，minutes = null从本次时间分析排除；保留原始行。缺失不等于测得 0；记录 missing time。
ID 10，minutes = −5从本次时间分析排除；保留原始行。经过时间不能为负；记录 negative time，不猜改 +5。
较晚出现的 ID 03，字段完全相同保留第一份，排除后来的同样副本。避免同一响应重复计入；日志需区分被排除的副本。
ID 15，mode = “ bus ”去首尾空格，规范为 Bus；保留此行。统一等价表达，不改变出行方式的含义。
ID 14，minutes = 120保留并标为 unusual。本字段未定义一个被违反的上限，也没有已证实的错误。

默认结果为 16 − 3 = 13 行。排除日志应包括 09、10 和第二份 03；标准化 ID 15 不减少行数，ID 14 仍在。不要把原始行直接删除或把缺失/负数覆盖成猜测值。对同一个 ID 有不同分钟数的情况，先核查来源和收集规则，再记录决定或保留 unresolved 标记；此数据集实际没有冲突重复。

规范等价标签直接体现“保持语义的清洗”。从当前分析视图排除不适用记录属于有理由的筛选，两者都必须说明。针对其他问题可能制定不同纳入规则，例如只统计 mode 时，缺失 minutes 的响应不一定需要排除；本节默认明确服务于时间分析。

实验室操作与学习记录

  1. 进入 Data tab，保持原始 16 行可查看，先不要应用规则。
  2. 每人写出三条排除及原因、一条标签变更、对 120 的决定，并预测保留行数。
  3. 应用规定规则，核对 13 行与排除日志；同时检查 ID 15 已变为 Bus、ID 14 仍有 120。
  4. 记录一次“预测—实际核对”的结果。若预测有误，用具体行和规则解释修正。
  5. 形成三句报告：数据来源与范围、处理决定与行数、一个尚未解决的适用性限制。

保持可选排除 120 的探索开关关闭。“去掉 120”只是下一课用于观察结论变化的 sensitivity check，不是默认清洗或质量修复。若看到 12 行，先检查是否启用了此探索；不要据此改写默认 13 行答案。

建议学习记录包含：原始行 ID/位置、原值或问题、操作、理由、所用规则、核对结果。无需抄整份表格。文件来源和处理记录应随数据版本保留，以便另一人按相同规则得到同一分析视图。

元数据与合并：讲解边界

一行里的 28、Bus、ID 15 是本表的主要数据；“单程分钟数”“允许哪些出行类别”“怎样收集”描述数据，是本表的元数据。元数据本身也可以成为其他研究的主要数据，本课先固定语境，避免把“所有文字都属于元数据”当成规则。

把 30 的单位标签从 minutes 改为 hours，不会自动把主要值变成 0.5。此时值仍为 30，但描述错误；真正的等价换算要同时变更数值与单位。说明数据与元数据不同，同时强调错误元数据仍可能使解释失真。

合并示例使用共享数据的两条记录拆成两表：02 为 25 分钟、4.0 km；03 为 12 分钟、0.8 km。第二张表故意倒序，以证明应按同一响应 ID 匹配。真实的跨来源合并还须检查 ID 是否共用同一含义、唯一性、单位和收集时间；不要根据“同名列”或“看起来差不多”虚构对应关系。本课不声称已经教学关系型数据库或 SQL。

评价与常见误区

证据充分表现需补救的表现
解释能给出主要值与相应元数据，并正确说出单位。把所有文字当元数据；把改标签当换算。
决策缺失、无效、重复、标签与异常值分别给出有依据的处理。统一填 0、取绝对值、删除所有高值或所有相同 ID。
核对13 行与三条排除都能从原始数据逐项说明。只记录行数，不知道具体删了什么。
边界承认合成自愿样本及关联数据的限制，按目的减少字段。以为清洗后就是所有学生的事实，或 ID 自动保证匿名。

可按每项 0–2 分作 8 分课堂诊断：0 无证据，1 部分正确，2 完整且有理由。建议至少 6/8 并纠正“缺失当零”“异常值自动删除”后进入 L08。这是教师形成性标准，不是 AP 评分规则。

Exit ticket 四项各 1 分：metadata；缺失是未知而非测得零；默认保留 120；13 行并能指向三条排除的日志与原始依据。第四项单写 13 不足。对第 2、3 项错误者，追加一组“缺失与真实零”“罕见但可能与已证实录入错误”的对比例子。
