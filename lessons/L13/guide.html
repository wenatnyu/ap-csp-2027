Lesson 13 · Counted Loops

Chapter 3 · 90 minutes · Preparing for May 2027

Chapter 3 · Programming lab

Purpose & Scope

固定非负整数次数的迭代，追踪计数器、累加器、更新先后、零次和两层小规模固定循环。学生实际编写读取三次分钟并求总量的程序，随后加入计数与平均值，不引入条件循环、列表或过程。

Lab Contract & Teacher Reference

打开本课对应页签。每条语句和每个大括号单独占一行；缩进表现嵌套。输入队列每行放一个 JSON 标量，例如数字 30、布尔值 true 或带双引号的文字。一次运行按 INPUT 调用顺序消耗队列；重置后再做下一测试。数字输入不加引号，假设符合题目范围。程序用 AP 伪代码，不依赖 Python。保留原始版本、预测表与修改后代码，不以工具显示答案代替纸面预测。

total ← 0
REPEAT 3 TIMES
{
  minutes ← INPUT()
  total ← total + minutes
}
DISPLAY(total)

三行队列10/20/30得60；0/0/0得0；30/45/15得90；180/180/180得540。斜线仅表示这里的输入分隔，实验室每个数必须单独一行。修改版先初始化count为0，在体内每轮加1；循环后average ← total / count，并显示total、count、average。30/45/15应显示90、3、30。

Teaching Decisions & Differentiation

初始化在循环前、读取和累计在体内、总结输出在循环后。实验室对次数表达式在进入循环时求值，但课堂使用常数次数或保持不变的n，不通过体内修改n探索参考表未明确的细节。零次示例只做追踪；平均值实践固定3次确保除数不为零。嵌套示例严格为2×3，不混合条件停止。25分钟实际编写不能由复制示例替代。

初学者先标执行路径，再列变量当前值；需要英语支架时使用 condition、branch、current value、iteration、expected output。熟练学生解释反例与等价变式，不靠超纲语法增加难度。图中用于练习的结果保留在展开答案内，课堂先独立作答再揭晓；可点击图解放大查看。

Assessment

课堂程序、选择题、书面题全部原创。作业12题、30分、约40分钟，其中Q5须两项全对且无多选才得1分；书面题每题四个独立评分点。按具体标准给分，正确的等价代码与命名可接受。不是官方 FRQ、历年真题或正式 Create 任务。

退出诊断：8、0、6；初始化一次避免清除之前贡献。若把循环次数当作变量结果，分别追踪次数与当前值；若把2×3误成2+3，用两行三格图重演。
