Purpose & Scope

学生能从布尔值走到正确代码块，区分独立IF和一次IF / ELSE选择。用当前值追踪，无需列表、循环或自定义过程。55–80分钟必须保留给学生实际编程，不以观看示范替代。

Lab Contract & Teacher Reference

打开本课对应页签。每条语句和每个大括号单独占一行；缩进表现嵌套。输入队列每行放一个 JSON 标量，例如数字 30、布尔值 true 或带双引号的文字。一次运行按 INPUT 调用顺序消耗队列；重置后再做下一测试。数字输入不加引号，假设符合题目范围。程序用 AP 伪代码，不依赖 Python。保留原始版本、预测表与修改后代码，不以工具显示答案代替纸面预测。

minutes ← INPUT()
IF(minutes >= 30)
{
  DISPLAY("Goal met")
}
ELSE
{
  DISPLAY("Keep going")
}

初版测试20、30、45应分别显示Keep going、Goal met、Goal met。修改为40分钟目标后，39/40/41应分别为Keep going/Goal met/Goal met。每次重置，代码一次只读取一个输入。

Teaching Decisions & Differentiation

重点误区：把ELSE当成第二个独立条件、认为假IF终止程序、把布尔变量当动态公式。用points从10改0和met保存true两例分别纠正。学生无需运行无效输入；代码也不宣称已验证范围。

初学者先标执行路径，再列变量当前值；需要英语支架时使用 condition、branch、current value、iteration、expected output。熟练学生解释反例与等价变式，不靠超纲语法增加难度。图中用于练习的结果保留在展开答案内，课堂先独立作答再揭晓；可点击图解放大查看。

Assessment

课堂程序、选择题、书面题全部原创。作业12题、30分、约40分钟，其中Q5须两项全对且无多选才得1分；书面题每题四个独立评分点。按具体标准给分，正确的等价代码与命名可接受。不是官方 FRQ、历年真题或正式 Create 任务。

退出诊断：true；不停止；ELSE不补运行；两个独立IF可同时执行。建议3/4且快照题正确后继续。
