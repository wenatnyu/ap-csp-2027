Lab Contract & Teacher Reference

本课使用项目编辑器中的TODO模板，学生完成AP伪代码。每条语句和每个大括号单独占一行；缩进表现嵌套。列表直接在程序中定义，用参数传入过程，本项目不需INPUT队列。保留预测、程序或实验配置、测试结果与修改后证据。先预测再运行，不以观看教师示范代替学生操作。

PROCEDURE countGoals(sessions, goal)
{
  hits ← 0
  FOR EACH minutes IN sessions
  {
    IF(minutes >= goal)
    {
      hits ← hits + 1
    }
  }
  RETURN(hits)
}
sessions ← [20,30,45,10]
count ← countGoals(sessions, 30)
DISPLAY(count)
IF(count >= 2)
{
  DISPLAY("On track")
}
ELSE
{
  DISPLAY("Try again")
}

必做：原数据goal30→2/On track；goal50→0/Try again；[29,30,31]goal30→2/On track；[0,0]goal30→0/Try again。可选空列表[]goal30返回0。每次调用的hits重新初始化，默认固定反馈标准count>=2，不计算比例。

Teaching Decisions & Differentiation

项目starter只含TODO，学生完成定义、遍历、选择、返回和调用反馈。有效分钟与goal为0–180整数，基本任务列表非空；不要求输入合法性验证。效率实验可打开Chapter_4_Algorithms_Lab.html#efficiency核验n、n²与2ⁿ的增长；n!只在课件表格与纸面活动中讨论；增长公式是说明性计数，不作为AP伪代码运算符。明确参数传入的是数据/阈值，列表与过程各自如何减少重复复杂度。

初学者先标执行路径，再列变量当前值；需要英语支架时使用 condition、branch、current value、iteration、expected output。熟练学生解释反例与等价变式，不靠超纲语法增加难度。图中用于练习的结果保留在展开答案内，课堂先独立作答再揭晓；可点击图解放大查看。
