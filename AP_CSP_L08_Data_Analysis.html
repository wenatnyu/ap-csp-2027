目标与准备

本课把 L05 数字表示、L06 压缩、L07 元数据与清洗连接到数据分析：提出能回答的问题，用程序筛选和汇总，选择图表，写有范围的证据结论。前置知识为基本算术和 L07 的清洗决定，不要求条件、循环、列表或过程代码。学生将操作现成分析工具；能够调用程序得到信息，并不要求本节自行实现统计程序。

唯一调查数据源为 Fictional Campus Commute Survey。所有记录均为合成教学数据，没有真实学生参与，也不是研究结论。其假想情境是一校、一晨、自愿参加的通勤调查，用于讨论采集范围与代表性。字段为匿名 response ID、main mode、one-way minutes、distance_km。

投影片英文为主，N 展开中文教师备注。先独立作答再揭晓。纸笔记录表与现成浏览器实验配合，允许两人共用设备但必须交换操作；每人最后提交自己的分析简报。课堂调查不是正式 Create 项目。

可直接布置的分析简报

使用 Chapter 2 Investigation Sheet。提交内容：一条可回答问题；当前数据的来源、单位和清洗规则；两项带单位及n的统计；一张有标题、类别、数值单位、组计数和视图说明的图；一条与证据一致的结论；一项有效限制；一次明确标记的敏感性比较及修改记录。

示例：“在这份保留13行的合成样本中，Bus的平均报告通勤时间为47.17分钟（n=6），Walk为11.25分钟（n=4）。这是本样本的组差异；两组距离和采集条件不同，不能据此断言换成步行会让所有人更快。基线保留120；若在敏感性视图省略它，Bus均值变为32.60分钟（n=5），该变化本身不证明120错误。”对应图应使用同一基线，不能把替代视图均值与基线计数混搭。

建议课堂8分量表：可回答问题1；可重现的视图与来源1；两项正确统计各1；图表标签与数据一致1；有范围的证据结论1；有效限制1；清洗与敏感性决定透明1。此量表与作业30分均为教师设计，不是AP官方评分标准。

误区与分层支持

  • 排序改变均值。 让学生重排三张数值卡，核对和值与数量没变；筛选才可能改变成员。
  • 图中每条长短是每个人的时间。 指出条形编码的是group mean，个体变化被汇总隐藏。
  • 异常值一律删掉。 区分违反定义的负时间、缺失值与尚未证实错误的120；保留日志与原始数据。
  • 样本均值最高代表所有人都更慢，或该方式造成更慢。 分别检查个体外推、群体外推和因果三个跳跃。
  • 样本多就自然没有偏差。 问采集过程是否仍遗漏同样的人、时间或场景。
  • 程序算出来就是可信。 核对单位、筛选状态、清洗规则和一组手算结果。

需要支架的学生可使用句式：In [specified view], [group] has [statistic with unit], based on n = [count]. This does not establish [unsupported inference] because [reason]. 先比较Walk四行手算再使用程序。较快学生解释为何三个组均值的简单平均不是全样本均值，或比较删除Bus记录为什么不影响Walk/Bike；不要求先学权重公式或新代码结构。

Exit三项各1分：Bus基线n=6；删120的变化不证明错误；距离或其他条件/观察性设计限制阻止因果结论。建议3/3结束本章；第2或3题错者用新情境补练结论边界，不能只凭会算均值判定掌握。
