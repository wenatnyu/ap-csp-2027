FRQ 要结合自己的程序来答

AP CSP 的现场书面回答围绕学生自己的 Create 程序和 Personalized Project Reference（PPR）。两道题包含四个作答提示，共 60 分钟；训练时准备一份有列表及学生自定义过程的练习程序，再使用对应套卷。

01 / PREPARE准备程序与 PPR确认自己能解释输入、输出、列表、过程与算法；标清要引用的代码。
02 / RESPOND先独立回答原题第一次可逐题讨论；熟悉后用未做过的一套限时 60 分钟。作答时直接回应题干。
03 / REVIEW按当年标准订正逐项指出自己的代码与回答提供了什么证据，再参考该套学生样例和评语。
没有唯一通用的完整答案。同一提示会因学生程序不同而有不同作答；官方评分标准和样例用于判断证据是否满足要求。

格式依据：College Board · AP CSP 考试说明。2024 年以前的 Create 作答格式与当前现场书面回答不同，本页集中使用 2024–2026 年材料。
